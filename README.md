# Portfolio d’Adrien Calvayrac

Portfolio réalisé en HTML, CSS et JavaScript pour présenter mon parcours, mes projets et ma recherche d’alternance en développement et gestion informatique.

- [Voir le site](https://adri9912.github.io/my-portfolio/)
- [Voir le dépôt GitHub](https://github.com/Adri9912/my-portfolio)

## Fichiers principaux

- `index.html` : accueil.
- `projets.html` : présentation des projets.
- `parcours.html` : parcours, compétences et progression.
- `contact.html` : coordonnées, CV, calendrier et formulaire.
- `style.css` : apparence, animations et adaptation au mobile.
- `app.js` : ouverture par lien direct et défilement vers les projets.
- `images/` : photo, captures et icônes.
- `documents/` : CV et calendrier d’alternance.
- `MODIFIER.md` : guide pour modifier le site.

## Ouvrir le site

Ouvrir `index.html` dans un navigateur. Aucune installation n’est nécessaire. Le formulaire utilise Formspree et nécessite une connexion Internet.

## Publication

Le site utilise GitHub Pages : **Settings > Pages > Deploy from a branch**, branche `main`, dossier `/ (root)`.

Après un commit et un push sur `main`, GitHub Pages met automatiquement le site à jour. Le déploiement se suit dans l’onglet [Actions](https://github.com/Adri9912/my-portfolio/actions).
